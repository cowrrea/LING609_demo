Calculate mean RT and standard error

  • The string values are weird!
unique(rt.df$type)
[1] "\"obj-ext\""  "\"subj-ext\""
unique(rt.df$region)
[1] "\"de1\""       "\"de\""        "\"dehnoun\""   "\"headnoun\"" 
[5] "\"headnoun1\""
mean.RT <- rt.df |>
  filter(region == "\"headnoun\"") |> # filter rows where region = headnoun
  group_by(type) |> # group by RC type
  summarize(mean_rt = mean(rt),
            n = n(),
            standard.error = sd(rt) / sqrt(n))
  
kable(mean.RT)
type mean_rt n standard.error
“obj-ext” 487.0073 275 21.13173
“subj-ext” 610.5404 272 46.68746

Summary

  • My findings seem to line up with what is reported in Figure 1 of Gibson and Yu (2013).

    • For SRCs, I found a mean RT = 610.5 ms (n = 272, standard error = 46.7).

    • For ORCs, I found a mean RT = 487 ms (n = 275, standard error = 21.1).
